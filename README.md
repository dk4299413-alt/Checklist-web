# CheckList Website

A responsive checklist/task manager built with **HTML, CSS and JavaScript**.

## Features

- Add tasks
- Low / Medium / High priority
- Mark tasks as completed
- Delete individual tasks
- All / Active / Completed filters
- Progress percentage
- Clear completed tasks
- Delete all tasks
- Data saved automatically in browser `localStorage`
- Mobile responsive
- No backend
- No database
- No API keys
- Works on GitHub Pages

## Files

- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — checklist functionality

## GitHub Pages

1. Create a GitHub repository, for example `checklist-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open the repository on GitHub.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/ (root)**.
7. Save.
8. Wait for GitHub Pages to deploy.
9. Open the generated Pages URL.

The website is completely static, so GitHub Pages can host it directly.
